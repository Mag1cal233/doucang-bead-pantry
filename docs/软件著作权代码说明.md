# 一粒画软件著作权代码说明

## 1. 文件用途

本文用于整理一粒画 2.0 的代码结构、主要原创功能和第三方数据边界，方便后续准备软件著作权申请材料。它不是法律意见，也不承诺登记结果。

## 2. 软件定位

一粒画面向拼豆爱好者，把图片处理、颜色匹配、库存约束、店内色号筛选、图纸编辑和制作进度整合在一个浏览器应用中。2.0 内测版采用本机优先方式，不要求账户或云端服务。

## 3. 主要原创模块

### 图像与图纸生成

`app/page.tsx` 包含图片裁剪、文字遮罩、连通背景清理、像素采样、调色偏转、颜色聚类、库存约束分配和多方案比较。生成结果会保留品牌、系列和色号，供后续图纸与采购计算使用。

### 店内色号区间

`app/palette-range.ts` 负责店内可买色号的独立建模。区间按色卡收录顺序解析，不按字符串大小排序；起止位置可以反向输入；多个区间会合并去重；缺货色号在最后一步排除。

颜色身份使用“品牌＋系列＋色号”三段键，避免 Hama、Perler 等品牌在不同尺寸系列中出现相同色号时互相覆盖。

### 库存与制作闭环

`app/page.tsx` 记录库存数量、安全库存、优先用色、图纸用量、采购缺口和完成状态。使用店内可买色号生成时只计算整件采购数量，不写入或扣减用户库存。

### 本机项目与迁移

草稿图片存入 IndexedDB，结构化项目、库存和店铺方案存入浏览器本机存储。项目包、店铺方案和 CSV 可以手动导出，供备份或跨设备迁移。

### 权益边界

`app/entitlements.ts` 只描述真实能力和已确定规则。内测阶段已开放的店内筛选、方案保存、导入与导出保持免费；尚未接入的云同步、账户和支付不会在界面中伪装成可用功能。

## 4. 第三方材料边界

- `app/brand-colors.ts` 中部分跨品牌参考色来自 `maxcleme/beadcolors`，遵循 MIT License。
- `app/mard-colors.ts` 是带来源和可信度标记的屏幕参考色数据，不宣称为官方实体测色结果。
- 第三方许可原文保留在 `THIRD_PARTY_NOTICES.md`。
- Next.js、React、vinext 等依赖由各自许可证约束，不作为本项目原创代码申报。

## 5. 注释与代码整理原则

- 注释解释业务原因、兼容背景和容易误判的边界，不逐行复述代码。
- 历史数据迁移代码可以保留，但应写明为什么存在。
- 不故意加入无效分支、重复变量或难以维护的代码来制造“人工痕迹”。
- 自动生成或外部来源的数据文件应在文件头注明来源，避免和原创算法混在一起。
